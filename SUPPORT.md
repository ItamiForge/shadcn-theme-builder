# Support policy

**Last verified against shadcn/ui:** August 2026 (Tailwind v4 CSS variables, `registry:theme` cssVars shape).

**Live demo:** https://itamiforge.github.io/shadcn-theme-builder/  
**Product docs:** https://itamiforge.github.io/itamiforge/docs/projects/theme-lab/

## In scope

- Dual light/dark semantic token editing and CSS / registry import-export
- Contrast, focus-ring, and gamut heuristics
- Component state matrix and diagnostic blocks
- Defects that break build, typecheck, or documented workflows
- Schema bumps when official shadcn theme conventions change
- GitHub Pages static export compatibility

## Out of scope

- Growing a marketing/block catalog for vanity metrics
- Guaranteeing accessibility of every composition after theming
- Supporting every third-party registry’s custom CSS
- Hosted accounts, cloud sync, Figma plugins, or AI generation

## Adding scenarios or blocks

Accepted only when it exercises a distinct design-system risk not already covered.

## Maintenance stance

Finite OSS project. Prefer a polished release and archive over unbounded feature growth.
